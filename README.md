# Repositório - 1º Semestre - Desenvolvimento de Software Multiplataforma

Este repositório contém as atividades e projetos desenvolvidos no primeiro semestre do curso de Desenvolvimento de Software Multiplataforma na FATEC Jacareí. As disciplinas abordadas incluem **Algoritmos e Lógica de Programação**, **Modelagem de Banco de Dados** e **Desenvolvimento Web I**. Durante o semestre, trabalhamos com as linguagens **JavaScript**, **HTML**, **CSS** e **SQL**.

## Disciplinas do Semestre

### **Algoritmos e Lógica de Programação**
Nesta disciplina, o foco foi no desenvolvimento de raciocínio lógico para resolver problemas de programação. Aprendemos a implementar algoritmos básicos e utilizar estruturas de controle, além de estudar a análise de complexidade.

### **Modelagem de Banco de Dados**
A disciplina de Modelagem de Banco de Dados abordou os conceitos de estruturação de dados em um banco relacional. Trabalhamos com modelagem entidade-relacionamento (ER) e aprendemos as operações fundamentais em SQL.

### **Desenvolvimento Web I**
Em Desenvolvimento Web I, focamos em criar páginas web utilizando HTML, CSS e JavaScript. Aprendemos a estruturar o conteúdo com HTML, estilizar com CSS e adicionar interatividade com JavaScript.

## Linguagens Utilizadas

- **JavaScript**: Usado para implementar a lógica dos algoritmos, bem como para criar funcionalidades dinâmicas nas páginas web. A linguagem foi aplicada principalmente na resolução de problemas de lógica e no desenvolvimento de interatividade nas páginas web.
  
- **HTML**: Utilizado para estruturar o conteúdo das páginas web. O HTML foi a base para a construção das interfaces dos projetos desenvolvidos, como formulários e layouts.

- **CSS**: Usado para estilizar as páginas web, definindo o layout, cores, fontes e demais aspectos visuais das páginas.

- **SQL**: Linguagem usada para manipulação de dados em bancos de dados relacionais. Foi fundamental na criação de tabelas e na realização de operações de consulta, inserção, atualização e remoção de dados em bancos como MySQL ou SQLite.
